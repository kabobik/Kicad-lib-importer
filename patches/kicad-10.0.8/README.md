# KiCad 10.0.8: миграция и исправление перезагрузки библиотек

Проверено 4 ноября 2026. Основа — официальный тег `10.0.8`, коммит
`e432beac2668303194ba2040274f9e5efe773fc0`.
[Описание выпуска](https://www.kicad.org/blog/2026/10/KiCad-10.0.8-Release/).

SHA-256 архива `cache/sources/kicad-10.0.8.tar.gz`:
`0723fedd82522fcd33cb9d8ad53979a35f6e4d3ec627c4e2e2708dfcba360574`.

## Состав серии

`series` содержит 20 патчей. Все 19 патчей предыдущей серии 10.0.7
(`0002..0020`) применяются без изменения контекста и переиспользуются по
относительным путям. Сохраняются группировка и настройки дерева, боковая
панель символов, drag-zoom, bus entry, фон листа, защита Reference базы,
исправление закрытия боковой панели и кириллических обозначений.

Новый [0021-footprint-library-reload-lifetime.patch](0021-footprint-library-reload-lifetime.patch)
применяется последним. Для переноса серии нужен весь каталог `patches/`,
поскольку `series` ссылается на совместимые патчи предыдущих версий.

## Причина падения и исправление

В дампе KiCad 10.0.7 от 4 ноября, 21:58 MSK обнаружен SIGABRT с сообщением
`free(): invalid pointer`. GUI находился в `FOOTPRINT::GetSearchTerms()`,
а фоновый поток заменял `PreloadedFootprints` и удалял прежние объекты.
Адрес объекта GUI совпал с первым уже удалённым элементом старого вектора.

После сохранения таблицы `InvokePcbLibTableEditor()` запускал асинхронную
загрузку и немедленно отправлял `MAIL_RELOAD_LIB`. `GetFootprints()` выдавал
сырые указатели после снятия блокировки; следующая замена кэша уничтожала
объекты до завершения чтения интерфейсом. Привязка сохранялась, поскольку
таблица записывается раньше. Ошибка относится к библиотекам посадочных мест
и не зависит от формата Altium. Опасная последовательность сохранилась в 10.0.8.

Патч исправляет оба звена:

- Кэш и результат `GetFootprints()` используют `shared_ptr`. Все потребители
  сохраняют полученный снимок до последнего чтения. Замена, перезапись или
  удаление записи больше не уничтожают объект, пока его читает интерфейс.
  Полные копии посадочных мест на каждое чтение не создаются.
- Немедленные уведомления из диалога таблицы удалены. Редактор, просмотрщик
  и CVPCB обновляются по окончании загрузки; просмотрщик добавлен к уже
  существующим уведомлениям о завершении.

Изменение касается внутреннего C++ API: нужно собирать всю версию согласованно,
как делают установщики, а не заменять один `.kiface` в установке 10.0.7.

## Установщики

Arch и Debian/Ubuntu теперь используют общий выбор новейшей поддержанной
стабильной серии. Без `--version` выбирается 10.0.8; RC и пустые каталоги
не выбираются. Явный `--version` сохраняет приоритет, а `--restore` продолжает
определять версию установленного пакета. Все применения и обратные проверки
патчей используют `--fuzz=0`. Несовместимый контекст останавливает работу.

Версия и хэш всей серии входят в ключ кэша, поэтому сборки 10.0.7 не будут
приняты за исправленную 10.0.8. Полная сборка Arch подготовлена и установлена
8 ноября 2026; результаты и пути кэша приведены ниже.

```bash
# Проверить обе платформенные процедуры без установки:
./scripts/build_and_install_arch.sh --check
./scripts/build_and_install_ubuntu.sh --check

# Arch: собрать в кэш, затем установить:
./scripts/build_and_install_arch.sh --version 10.0.8 --build-only --rebuild
./scripts/build_and_install_arch.sh --version 10.0.8 --from-cache

# Debian/Ubuntu:
./scripts/build_and_install_ubuntu.sh --version 10.0.8 --build-only --rebuild
./scripts/build_and_install_ubuntu.sh --version 10.0.8 --from-cache --update-libraries
```

## Проверки

- Оба установщика в режиме `--check` выбрали 10.0.8 и применили все 20 патчей
  к чистому архиву без fuzz.
- CMake настроен с QA-тестами. Все 38 изменённых `.cpp` всей серии прошли
  проверку `-fsyntax-only` по командам из `compile_commands.json` с настоящими
  заголовками KiCad и зависимостей. Это проверка типов и синтаксиса, без линковки.
- Все 39 Python-тестов проекта прошли. Среди них — выбор версии, откат,
  отклонение неверного контекста, кириллические обозначения на 10.0.7/10.0.8
  и регрессия времени жизни посадочных мест.
- Новый тест `tests/test_footprint_snapshot.py` извлекает настоящий getter
  и объявления кэша из архива, применяет полную серию и компилирует обвязку
  с AddressSanitizer/UBSan. Исходный getter теряет объект после замены кэша;
  исправленный выдерживает замену, удаление элемента и удаление библиотеки.
  Проверяется освобождение после ухода последнего читателя. LeakSanitizer
  отключён для совместимости с ограниченным окружением; время жизни объектов
  дополнительно проверяется счётчиком.
- В патч включён QA-тест KiCad `FootprintSnapshotSurvivesBackgroundReload`:
  настоящая библиотека перечитывается фоновым потоком, затем GUI-снимок
  повторно читает `GetSearchTerms()`. Файл теста проверен компилятором;
  запуск полного `qa_pcbnew` не выполнялся.

```bash
python3 -m unittest discover -s tests -v

# После сборки KiCad с KICAD_BUILD_QA_TESTS=ON:
./build/qa/tests/pcbnew/qa_pcbnew --run_test=FootprintLibraryAdapter/FootprintSnapshotSurvivesBackgroundReload
```

## Сборка и восстановление Arch — 8 ноября 2026

Обновление pacman от 5 ноября заменило локальную 10.0.7-2 официальным пакетом
10.0.8-1.1. SHA-256 системных файлов совпадали с манифестом официального пакета.
Серия патчей повторно проверена и установлена поверх текущего пакета:

- Все 20 патчей применены к чистому архиву с `--fuzz=0`; SHA-256 архива совпал
  с указанным выше.
- Выполнена полная Release-сборка с Python/wxPython, SPICE, 3D и переводами.
  Начальный запуск на двух потоках продолжен на 12 с сохранением объектов.
  Унаследованный приоритет `nice -4` понижен до `nice 10` для отзывчивости GUI.
- Пройдены 37 тестов проекта. Набор для исторической версии 10.0.7 пропущен
  из-за отсутствия её архива; проверки текущей 10.0.8 выполнены.
- До и после установки успешны запрос версии, импорт обеих тестовых `.SchLib`,
  экспорт netlist схемы и SVG медных слоёв платы. Для экспорта использовались
  временные копии проекта Panel. Python-модуль `pcbnew` загрузил плату:
  18 посадочных мест, 68 дорожек/переходных отверстий.
- После установки проверено совпадение 792 файлов и символьных ссылок с кэшем
  сборки (SHA-256 файлов и целей ссылок). Ресурсы KiCad найдены в `/usr/share/kicad`.
- В `/etc/pacman.conf` установлено `IgnorePkg = cursor-bin kicad`.
  Библиотеки `kicad-library` и `kicad-library-3d` не заблокированы.
  Резервная копия: `/etc/pacman.conf.before-kicad-pin-20261108T012448`.

Готовая сборка: `cache/kicad-arch-10.0.8-1489f341d942/` (около 579 МиБ).
Исходные системные файлы сохранены в `cache/kicad-arch-10.0.8-original/root/`.
Для отката используется штатный установщик:

```bash
./scripts/build_and_install_arch.sh --version 10.0.8 --restore
```

Логи проверки патчей, тестов, установки и экспорта сохранены внутри кэша в
`verification-2026-11-08/`; их удаляет `--clean-cache` вместе с этой сборкой.
Полные журналы компиляции находятся в `kicad-src-arch/build/` (`build.log`,
`build-resume-j12.log`, `install.log`). Остановка первого запуска в `build.log`
была намеренной для смены числа потоков, а не ошибкой компиляции.

Интерактивная проверка GUI и полный `qa_pcbnew` не выполнялись.
Для проверки GUI на копии проекта: открыть редактор
посадочных мест, добавить библиотеку (включая Altium), дождаться обновления
дерева, открыть элемент, удалить и повторно добавить привязку. Повторить с
открытым просмотрщиком/CVPCB и включённой группировкой; после перезапуска
проверить сохранность таблицы.
